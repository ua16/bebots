# Contributing

Requires [Bun](https://bun.sh).

```bash
bun install
bun run typecheck
bun run lint
bun run test
```

Keep PRs small and focused.

Refrain from opening PRs for features without discussion. Bug fixes are
always welcome, make sure you include steps to reproduce a bug in your PR
description.

Use `bun` for all package management and scripts — not npm or pnpm.
